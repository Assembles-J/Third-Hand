# 产品与接口设计

## 核心页面

| 页面 | 新手体验 | 核心动作 |
| --- | --- | --- |
| 今日 | 一句话说明“为什么与你有关” | 展开证据、打开原文、稍后看 |
| 持仓 | 成本、仓位、行业集中度（非收益承诺） | 手动录入、CSV 导入、编辑 |
| 消息 | 事件按公司 / 行业 / 概念聚合 | 过滤、关联跳转、订阅 |
| 词条 | 定义、常见影响、反例、风险提示 | 查看原文出处 |
| 我的关注 | 自选股、行业、关键词、提醒频率 | 添加、静音、调整优先级 |

## 信息处理流水线

`采集 → 来源校验 → 去重 → 实体识别 → 事件分类 → 关联图谱 → 个性化排序 → 可解释卡片`

每张卡必须包含：来源 URL、发布时间、关联实体、系统生成时间、置信度/待核实提示。

## API（当前原型）

- `GET /health`：服务状态。
- `GET /v1/feed?symbols=600519,000001`：按持仓过滤的示例信息流。
- `GET /v1/glossary/{term}`：词条卡。
- `POST /v1/holdings/import`：接收 CSV 内容并验证，不保存敏感凭证。

## 风险与边界

- 不输出“买入/卖出/目标价/保证收益”等个性化投资建议。
- 行情、新闻、公告有延迟或错误可能，界面需标记时效和来源。
- 第三方数据源和同花顺导出格式均应在接入前审查协议与授权。
- 个人持仓属于敏感财务数据：最小化采集、可导出/删除、静态加密、访问日志。
